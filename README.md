# Predictive Modelling on Spotify Tracks Dataset

A data mining project exploring a dataset of music tracks with audio features and metadata. The work covers exploratory data analysis, clustering (k-means and DBSCAN), and predictive modelling: binary classification and regression to predict track popularity from the available features. Preprocessing and modelling are done with scikit-learn pipelines; the analysis is documented in a Jupyter notebook.

## Contents

- **Notebook** – EDA, clustering, classification, and regression with commentary and visualisations.
- **Data** – `tracks2026.csv` (audio features and metadata for tracks across several genres).

## Requirements

- Python 3
- pandas, numpy, matplotlib, seaborn, scikit-learn

## Usage

Place `tracks2026.csv` in the same directory as the notebook and run the cells in order.
